# API Test Automation Suite (C# · Playwright · Reqnroll)

Automated API test suite built with C#, Playwright and Reqnroll (BDD), running in a GitHub Actions CI pipeline.

## What it covers
- Functional API tests written as readable Gherkin scenarios (Given / When / Then)
- Positive and negative cases: status codes, response body and schema checks
- Automatic test runs on every push through GitHub Actions

## Tech stack
C# · .NET · Playwright · Reqnroll · NUnit · GitHub Actions

## How to run
dotnet restore then dotnet test
